# 🏺 Проєкт «Фенікс» (feniks3dbrd)

Вебсайт для дипломного проєкту та сімейного міні-бізнесу з продажу 3D-фігурок, брелків, ламп та інших виробів, виготовлених на власному 3D-принтері[cite: 1, 5, 6, 7].

## 📂 Структура проєкту

- `index.html` — Головна сторінка сайту[cite: 4].
- `brelky.html` — Сторінка категорії «Брелки»[cite: 1].
- `statues.html` — Сторінка категорії «Статуетки»[cite: 10].
- `lamps.html` — Сторінка категорії «Лампи».
- `other.html` — Сторінка категорії «Інше» (різні 3D-товари)[cite: 6].
- `home.css` — Головний файл стилів (формлення, сітка, теми)[cite: 3].
- `server.js` — Серверна частина на Node.js (Express), що обробляє API та запити.
- `db.json` — Локальна база даних (JSON-формат) для збереження інформації про фігурки та товари[cite: 2, 9].
- `package.json` — Конфігурація Node.js та залежності проєкту[cite: 7].

## ⚙️ Залежності та технології

- **Frontend:** HTML5, CSS3 (Flexbox, адаптивна верстка).
- **Backend:** Node.js, Express (^5.2.1)[cite: 7, 9].
- **База даних:** JSON-файлова структура (`db.json`)[cite: 2, 9].
